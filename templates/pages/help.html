How Auto-Snapshot Works

The application monitors your project folders for file changes. When changes are detected, it automatically creates a 'snapshot' by committing the changes to a local Git repository.

Key Concepts

  • Project: Any folder on your system you choose to monitor.
  • Snapshot: A Git commit representing the state of your project at a specific time.
  • Forgejo Push (Optional): Snapshots can be automatically pushed to a remote repository on Forgejo.
